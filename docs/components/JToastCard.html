JToastCard

Notificaciones flotantes estilo tarjeta (card) con colores sólidos/opacos de alto contraste, icono temático, botón de cierre y animación fluida de entrada de abajo hacia arriba (estilo Avast clásico) o desde la parte superior.

Uso en JavaFX

import com.jjarroyo.components.JToastCard;
import javafx.stage.Window;
import javafx.util.Duration;

// 1. Alerta de Amenaza estilo Avast (Bottom-Right por defecto)
JToastCard.showDanger(
    stage,
    "¡Se ha detectado una amenaza!",
    "Win32:Evo-gen [Susp] ha sido bloqueado y neutralizado."
);

// 2. Notificación en esquina superior derecha
JToastCard.show(
    stage,
    "Uso de Memoria Elevado",
    "El consumo de RAM ha superado el 85%.",
    JToastCard.Type.WARNING,
    JToastCard.Position.TOP_RIGHT,
    Duration.millis(4500)
);

// 3. Fluent Builder API
JToastCard.make("Actualización Lista", "La versión v2.2.0 ya está disponible.")
    .type(JToastCard.Type.INFO)
    .position(JToastCard.Position.BOTTOM_RIGHT)
    .duration(5000)
    .show(stage);

Referencia de la API

Método / Enum Descripción
JToastCard.Type DANGER, WARNING, SUCCESS, INFO, DEFAULT
JToastCard.Position BOTTOM_RIGHT (default), TOP_RIGHT, BOTTOM_LEFT, TOP_LEFT, BOTTOM_CENTER, TOP_CENTER
show(owner, title, msg, type, pos, duration) Muestra la tarjeta animada con todos los parámetros personalizados.
showDanger / showWarning / showSuccess / showInfo Atajos estáticos directos en la posición inferior derecha con temporizador adaptativo.
