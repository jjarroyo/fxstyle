JRibbon

Insignia o cinta esquinera diagonal promocional para destacar tarjetas (JCard), productos o planes de precios (ej. "POPULAR", "PRO", "-30% OFF", "BETA").

Variantes y Uso 

// Envolver cualquier JCard o nodo con una cinta esquinera
JCard proCard = createCard("Plan Pro", "$19 / mes");
Node cardWithRibbon = JRibbon.wrap(proCard, "POPULAR", Variant.PURPLE);

// Especificar posición en esquina izquierda
Node leftRibbonCard = JRibbon.wrap(myCard, "BETA", Variant.WARNING, Position.TOP_LEFT);

// Crear ribbon individual y contenedor explícito
JRibbon ribbon = new JRibbon("-50% OFF", Variant.DANGER);
JRibbon.JRibbonContainer container = new JRibbon.JRibbonContainer(productCard, ribbon);

API Reference

Constructor / Método Descripción
JRibbon(String text) Crea una cinta con texto en posición predeterminada TOP_RIGHT y variante PRIMARY.
JRibbon(text, Variant, Position) Crea una cinta definiendo texto, variante de color y posición.
setVariant(Variant variant) Establece la variante contextual (PRIMARY, SUCCESS, DANGER, WARNING, PURPLE, DARK).
setPosition(Position position) Establece la posición esquinera (TOP_RIGHT o TOP_LEFT).
JRibbon.wrap(node, text, variant) Método utilitario estático para envolver rápidamente cualquier nodo con la cinta.
