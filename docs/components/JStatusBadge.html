JStatusBadge

Insignia de estado con indicador de punto brillante (status dot), animación de pulso opcional para estados en vivo (online / live status) y estilos contextuales Metronic/Tailwind.

Variantes y Estados

Online (Live) Offline Ausente Procesando Inactivo Premium 
// Estado Activo / Online con Animación de Pulso
JStatusBadge liveBadge = new JStatusBadge("Online", Status.ONLINE, true);

// Estado Offline o Inactivo
JStatusBadge offlineBadge = new JStatusBadge("Desconectado", Status.OFFLINE);

// Estado Procesando / Informativo con Pulso
JStatusBadge processingBadge = new JStatusBadge("Sincronizando...", Status.PROCESSING, true);

// Uso del Builder Fluido
JStatusBadge customBadge = new JStatusBadge()
    .withText("Servidor OK")
    .withStatus(Status.SUCCESS)
    .withPulse(true);

Animación de Pulso (Live Pulse)

Activa el efecto de pulso con setPulse(true) o withPulse(true) para resaltar visualmente cuando un servicio, usuario o proceso está en ejecución en vivo. 

// Encender / Apagar el pulso dinámicamente
statusBadge.setPulse(true);  // Inicia animación suavizada de escalado y opacidad
statusBadge.setPulse(false); // Detiene la animación y restaura el punto a su estado normal

API Reference

Constructor / Método Descripción
JStatusBadge() Crea una insignia con texto "Active", estado SUCCESS sin pulso.
JStatusBadge(String text) Crea una insignia con texto personalizado y estado SUCCESS.
JStatusBadge(String text, Status status) Crea una insignia con texto y estado especificado.
JStatusBadge(text, status, boolean pulse) Crea una insignia completa definiendo texto, estado y animación de pulso.
setStatus(Status status) Cambia el estado contextual y ajusta los colores de fondo, borde y punto.
setPulse(boolean pulse) Activa o desactiva la animación de pulso continuo en el punto de estado.
setText(String text) Actualiza el contenido textual de la etiqueta de la insignia.

Enum JStatusBadge.Status

Valor Enum Alias Descripción
