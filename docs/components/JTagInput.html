JTagInput

Campo de entrada interactivo que organiza datos en etiquetas (chips) flotantes con soporte de ajuste automático de línea (wrap), límites de cantidad, rechazo de duplicados y estilos dinámicos.

Ejemplo Interactivo (Representación Web)

JavaFX ✕ TailwindCSS ✕ 
// Creación e inicialización básica de JTagInput
JTagInput tagInput = new JTagInput();
tagInput.setPlaceholder("Escribe y presiona Enter...");

// Agregar etiquetas de forma programática
tagInput.getTags().addAll("JavaFX", "TailwindCSS");

Características de Configuración

  • Delimitador de ingreso: Se puede agregar un tag pulsando la tecla Enter o ingresando una coma , en el teclado.
  • Eliminación asistida: Pulsar Backspace cuando el input está vacío remueve automáticamente la última etiqueta añadida.
  • Control de Duplicados: Opciones para habilitar o rechazar términos duplicados dentro de la lista de etiquetas.
  • Límites Estrictos: Se puede definir un número máximo de etiquetas permitidas. Una vez alcanzado, el componente bloquea el ingreso de nuevos términos hasta que se libere espacio.

API Reference

Método Descripción
getTags() Retorna la lista observable (ObservableList<String>) para leer o modificar las etiquetas.
setPlaceholder(String text) Establece el texto informativo en el campo de entrada cuando no hay tags.
setMaxTags(int max) Establece la cantidad máxima de etiquetas permitidas. El valor -1 representa ilimitadas.
setDuplicateAllowed(boolean allow) Define si se permiten o no etiquetas con el mismo nombre de texto. Por defecto es false.
setTagColor(JChip.ChipColor color) Define el color de los tags usando el enumerador (PRIMARY, SUCCESS, DANGER, WARNING, INFO, SLATE).
setTagVariant(JChip.Variant variant) Define la variante visual del chip (SOFT, FILLED, OUTLINED).
setTagSize(JChip.Size size) Ajusta el tamaño del chip de los tags (SM, MD, LG).
clear() Limpia todo el texto del input y elimina todas las etiquetas registradas en el componente.
