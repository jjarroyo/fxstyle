JTooltip

Componente de tooltip moderno estilizado con utilidades de FxStyle. Reemplaza el tooltip oscuro nativo de JavaFX por un diseño elegante, suave y con soporte para variantes contextuales de color. Hereda de `javafx.scene.control.Tooltip`.

Variantes y Estilos

Tooltip Light Variant.LIGHT
Tooltip Default Variant.DEFAULT
Información útil Variant.INFO
Operación exitosa Variant.SUCCESS
Acción destructiva Variant.DANGER 
// Crear un JTooltip directamente
JTooltip tooltipLight = new JTooltip("Información secundaria");
JTooltip tooltipDanger = new JTooltip("Eliminar registro permanentemente", JTooltip.Variant.DANGER);

// Cambiar variante dinámicamente
tooltipLight.setVariant(JTooltip.Variant.INFO);

// Asignar a un botón nativo o FxStyle
JButton btn = new JButton("Guardar");
btn.setTooltip(tooltipLight);

Instalación Rápida Estática

Puedes instalar un JTooltip en cualquier nodo de JavaFX con una sola línea de código utilizando el método helper estático JTooltip.install(). 

// Instalación rápida con variante por defecto (LIGHT)
JTooltip.install(buttonSave, "Guardar los cambios actuales");

// Instalación rápida especificando una variante de color
JTooltip.install(buttonDelete, "Advertencia: Esta acción no se puede deshacer", JTooltip.Variant.DANGER);
JTooltip.install(iconInfo, "Ver detalles del producto", JTooltip.Variant.INFO);

API Reference

Constructor / Método Descripción
JTooltip() Crea un JTooltip vacío con variante LIGHT.
JTooltip(String text) Crea un JTooltip con texto y variante LIGHT.
JTooltip(String text, Variant variant) Crea un JTooltip con texto y la variante de color especificada.
setVariant(Variant variant) Aplica una variante de color y configura los tiempos de aparición (150ms delay, 10s duración).
install(Node node, String text) Método estático para crear e instalar un JTooltip claro en un nodo.
install(Node node, String text, Variant variant) Método estático para crear e instalar un JTooltip con variante en un nodo.

Enum JTooltip.Variant

Valor Enum Clase CSS aplicada Descripción
LIGHT tooltip-light Fondo blanco con texto oscuro y borde suave (por defecto).
DEFAULT tooltip Fondo oscuro con texto blanco.
INFO tooltip-info Estilo azul informativo.
SUCCESS tooltip-success Estilo verde de éxito/confirmación.
DANGER tooltip-danger Estilo rojo de alerta/destructivo.
