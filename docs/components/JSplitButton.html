JSplitButton

Un componente de botón dividido que combina un botón de acción principal en el lado izquierdo y un gatillo con flecha para menú desplegable en el lado derecho.

Descripción General

JSplitButton extiende de HBox y agrupa dos instancias de JButton fusionadas mediante CSS con esquinas redondeadas compartidas. Permite ejecutar una acción directa al presionar el botón principal o desplegar un menú desplegable de acciones alternativas al presionar la flecha.

Ejemplo de Uso

// Crear un JSplitButton con acción principal y menú
JSplitButton saveBtn = new JSplitButton("Guardar Cambios", () -> save())
    .addMenuItem("Guardar y Salir", () -> saveAndClose())
    .addMenuItem("Guardar como Borrador", () -> saveDraft())
    .addSeparator()
    .addMenuItem("Descartar", () -> discard());

// Definir variante de color
saveBtn.setVariant(JSplitButton.Variant.SUCCESS);

Variantes Disponibles

Variant.PRIMARY

Estilo primario predeterminado de la biblioteca.

Variant.SUCCESS

Variante verde para acciones positivas (publicar, guardar).

Variant.DANGER

Variante roja para acciones destructivas o críticas.

Variant.WARNING

Variante amarilla / ámbar para advertencias.

Variant.SECONDARY

Variante gris neutra para acciones secundarias.

Variant.OUTLINE

Estilo con borde y fondo transparente.

Métodos Principales

Método Retorno Descripción
addMenuItem(String title, Runnable action) JSplitButton Agrega una opción de menú con su manejador de evento.
addSeparator() JSplitButton Agrega un separador visual entre opciones del menú desplegable.
setVariant(Variant variant) void Establece la variante visual del botón principal y la flecha.
withAction(Runnable action) JSplitButton Asigna la acción del botón principal de forma fluida.
getMainButton() JButton Retorna la instancia del JButton principal.
getContextMenu() ContextMenu Retorna la instancia del ContextMenu asociado.
