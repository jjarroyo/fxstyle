Animaciones y Transiciones

Motor utilitario de animaciones declarativas (JAnimation), contadores numéricos animados (JAnimatedNumber) y contenedores de cambio de vista con transición fluida (JAnimatedSwitcher).

1. Motor Utilitario Declarativo (JAnimation)

Aplica efectos suaves a cualquier Node de JavaFX con una sola línea de código sin crear objetos Timeline o Transition manualmente. 

// Efectos de Entrada / Desplazamiento
JAnimation.fadeIn(myCard);
JAnimation.slideInUp(myCard);
JAnimation.slideInDown(myCard);
JAnimation.slideInLeft(myCard);
JAnimation.slideInRight(myCard);
JAnimation.zoomIn(myCard);
JAnimation.popIn(myCard);

// Efectos de Feedback / Atención
JAnimation.shake(passwordField);  // Sacudida de error
JAnimation.pulse(actionButton);    // Latido para llamar la atención
JAnimation.bounce(notification);   // Salto elástico

// Configuración Avanzada y Callbacks Encadenados
JAnimation.slideInUp(dialogNode, Duration.millis(500), 30)
          .delay(Duration.millis(150))
          .onFinished(() -> System.out.println("¡Animación finalizada!"))
          .play();

2. Contador Numérico Animado (JAnimatedNumber)

Control Label especial para animar cambios numéricos (conteo de 0 a X) con curvas de aceleración suaves (EaseOutCubic). 

// Crear contador financiero
JAnimatedNumber numRevenue = new JAnimatedNumber(0, 15420.50);
numRevenue.setPrefix("$ ");
numRevenue.setDecimalPlaces(2);
numRevenue.setDuration(Duration.seconds(1.5));

// Animar suavemente hacia un nuevo valor
numRevenue.animateTo(28750.00);

3. Contenedor con Transición entre Vistas (JAnimatedSwitcher)

Contenedor inspirador en AnimatedSwitcher de Flutter y AnimatePresence de Framer Motion. Al invocar setContent(newView), reemplaza la vista con animación fluida. 

// Instanciar contenedor con tipo de animación
JAnimatedSwitcher switcher = new JAnimatedSwitcher();
switcher.setSwitchAnimation(SwitchAnimation.SLIDE_LEFT);
switcher.setDuration(Duration.millis(400));

// Cambiar de vista con animación
switcher.setContent(step2FormView);

4. Tarjeta 3D Giratoria (JFlipCard)

Tarjeta interactiva con 2 caras (Frontal y Trasera) que realiza una rotación 3D de 180° en el eje Y o X al hacer clic o al pasar el ratón. 

// Crear tarjeta 3D con cara frontal y trasera
JFlipCard flipCard = new JFlipCard(frontView, backView);

// Girar manualmente al hacer clic o por evento
flipCard.flip();

// O activar giro automático en hover
flipCard.setFlipOnHover(true);

5. Efecto Onda de Clic (JRippleContainer)

Agrega el efecto de onda circular (Ripple Wave de Material Design y Tailwind) a cualquier botón, tarjeta o control de JavaFX al hacer clic. 

// Envolver un control con el efecto de onda
JRippleContainer ripple = new JRippleContainer(myButton);
ripple.setRippleColor(Color.web("#3b82f6", 0.3));

6. Marquesina Animada (JMarquee)

Cinta o banner de texto de desplazamiento continuo para anuncios, noticias o tickers en tiempo real con pausa al hacer hover. 

// Banner marquesina continuo
JMarquee marquee = new JMarquee("🚀 [NUEVA VERSIÓN] FxStyle v2.2.0 disponible");
marquee.setSpeed(75.0); // píxeles por segundo
marquee.setPauseOnHover(true);

API Reference

Clase JAnimation

Método Estático Descripción
fadeIn(Node node) Aparece suavemente aumentando la opacidad de 0 a 1.
fadeOut(Node node) Desaparece suavemente reduciendo la opacidad a 0.
slideInUp(Node node) Desplaza de abajo hacia arriba con efecto de entrada.
slideInDown(Node node) Desplaza de arriba hacia abajo con efecto de entrada.
zoomIn(Node node) Escala de 0.7 a 1.0 con opacidad progresiva.
popIn(Node node) Efecto pop elástico con rebote sutil.
shake(Node node) Sacudida horizontal para indicar errores o entradas inválidas.
pulse(Node node) Pulsación/escalado temporal para llamar la atención.
bounce(Node node) Rebote vertical doble para notificaciones.

Clase JFlipCard

Método Descripción
flip() Alterna la tarjeta de 0° a 180° en 3D.
setFront(Node node) / setBack(Node node) Define los contenidos del frente y reverso.
setFlipOnHover(boolean flipOnHover) Gira automáticamente al pasar el cursor sobre la tarjeta.

Clase JRippleContainer

Método Descripción
setContent(Node node) Envuelve el control base que recibirá la animación ripple.
setRippleColor(Paint color) Establece el color y opacidad de la onda expansiva.

Clase JMarquee

Método Descripción
setText(String text) Establece el texto en desplazamiento continuo.
setSpeed(double pxPerSec) Velocidad del desplazamiento en píxeles por segundo.
setPauseOnHover(boolean pauseOnHover) Pausa el desplazamiento al pasar el ratón por encima.

Clase JAnimatedNumber

Método Descripción
animateTo(double targetValue) Inicia la animación suave desde el valor actual hacia el objetivo.
setPrefix(String prefix) Establece un prefijo textual (ej: "$ ", "EUR ").
setSuffix(String suffix) Establece un sufijo textual (ej: "%", " usuarios").
setDecimalPlaces(int places) Define el número de lugares decimales formateados.

Clase JAnimatedSwitcher

Método Descripción
setContent(Node newContent) Reemplaza el nodo actual animando la transición.
setSwitchAnimation(SwitchAnimation anim) Define la animación (FADE, SLIDE_LEFT, SLIDE_RIGHT, SLIDE_UP, SLIDE_DOWN, ZOOM).
