JGauge & JGaugeCard

Tacómetros y medidores reactivos para dashboards y dispositivos IoT en tiempo real. Cuentan con movimiento físico suave de aguja (Punto A → Punto B), arcos dinámicos, semáforo de estados y múltiples estilos de instrumentación.

Estilos de Instrumentación IoT Disponibles

1. RADIAL_CLASSIC (Tacómetro deportivo 270°)

Ideal para RPM de motores, velocímetros de vehículos y rotación de ejes industriales. Incluye zona de peligro / redline y multiplicador x1000.

2. SEMI_CIRCLE (Semicírculo Térmico 180°)

Ideal para temperatura en cámaras frigoríficas o calderas. Arco continuo dividido en zonas: Óptimo (verde), Advertencia (amarillo) y Crítico (rojo).

3. ARC_PROGRESS (Arco de Progreso Moderno)

Puntero exterior y barra gruesa reactiva que se llena en tiempo real. Ideal para humedad relativa (% HR) o porcentaje de batería (SOC).

4. LINEAR (Regla Analógica Horizontal)

Regla horizontal graduada con cursor deslizante reactivo. Ideal para voltajes de batería (12V, 24V, 48V) o potencia de señal RSSI.

5. AMPERAGE (Cero Central - Flujo Bidireccional)

Cero central a las 12:00 (-30A a +30A). Muestra flujo de carga solar hacia la derecha (verde) o descarga de la batería hacia la izquierda (ámbar).

6. WIND_SPEED (Anemómetro Meteorológico)

Marcador con escala de viento Beaufort (Brisa suave, Moderado, Fuerte, Tormenta) y aguja aerodinámica de veleta.

7. PRESSURE (Manómetro Industrial)

Dial de presión industrial para compresores (Bar / PSI) con dial de seguridad concéntrico y aguja de contrapeso circular.

8. LEVEL_VERTICAL (Nivel de Fluido / Tanque)

Silueta vertical de tanque/depósito de combustible o agua con llenado reactivo y marcas laterales de capacidad.

Ejemplo de Uso Rápido 

// 1. Instanciación con preset listo para usar:
JGauge rpmGauge = JGauge.createRpmGauge();

// 2. Tarjeta con cabecera y LED de estado reactivo:
JGaugeCard card = new JGaugeCard("Motor de banda", "Velocidad de eje", rpmGauge);

// 3. Conexión a streams IoT en tiempo real (MQTT / WebSocket / Serial):
// La aguja viaja suavemente del punto actual al nuevo punto sin saltos bruscos:
mqttClient.subscribe("sensores/motor/rpm", (topic, msg) -> {
    double valor = Double.parseDouble(new String(msg.getPayload()));
    Platform.runLater(() -> rpmGauge.setValue(valor));
});
